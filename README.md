# Huss Valley

Movement and dash controls for Matcha, using [JDUI](https://github.com/jdev-studio/jdui).

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/jdev-studio/huss-valley-script/main/Valley"))()
```

- **Right Shift** opens or hides the menu.
- For infinite dash, turn on **Infinite dash (no cooldown)** on the Movement tab. Press Space and turn to dash again as soon as a dash ends.
- For longer dashes, turn on **Longer dash** on the Movement tab and set **Dash distance** (1.1x to 3x).
- Enable **unsafe Lua execution** in Matcha for dash tuning.
- Settings save automatically and restore when you reload.
